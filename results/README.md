# Experimental results

This directory will contain the raw and processed outputs from the two controlled experimental sets.

```text
results/
├── set_A_no_cooling/
│   ├── csv/
│   ├── telemetry/
│   └── logs/
└── set_B_active_cooling/
    ├── csv/
    ├── telemetry/
    └── logs/
```

Set A represents operation without active cooling. Set B repeats the same benchmark methodology with active cooling installed. Raw files should be preserved wherever possible so that derived figures and summary tables can be traced back to the original measurements.
